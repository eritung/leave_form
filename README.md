# 艾迪英特請假單 Streamlit App

## 功能

- 使用內建 `艾迪英特請假單.xlsx` 作為預設模板。
- 支援使用者在頁面上直接上傳原本的假單 xlsx 作為模板。
- 填寫後自動同步輸出：公司留存、請假者留存。
- 保留原始 Excel 版型、合併儲存格、框線與列印範圍。
- UI 已調整為日系紙感風格，表單區塊分為：模板設定、基本資料、請假時間、簽核欄位、輸出前確認。

## 使用方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 模板上傳注意事項

可以直接上傳原本的假單 xlsx。
但目前程式是依照原始假單欄位座標填入資料，因此若新版模板有大幅移動欄位位置，例如請假人、代理人、假別、事由、時間、簽核欄位的位置改變，就需要同步調整 `SECTION_ROWS` 與欄位對應。

## 目前欄位對應

- 申請日期：I/K/M 欄
- 請假人：D 欄
- 代理人：K 欄
- 假別：D/F/H/J/M 欄
- 事由：D 欄
- 開始時間：C/E/G/I/K 欄
- 請假天數：M 欄
- 結束時間：C/E/G/I/K 欄
- 簽核：C/G/K 欄
